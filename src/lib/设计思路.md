# 公众号文章样式 · 设计思路（暖阳 / 素笺 / 清露）

> 这是一套面向「微信公众号文章」的阅读样式方案，由设计侧产出，供开发（CodeBuddy）接入 `src/lib/theme.ts` 的主题系统。
> 三套样式已分别落地为独立文件：`theme-warm-sun.ts` / `theme-ink.ts` / `theme-fresh.ts`，本文件说明其设计意图与接入方式。
> **注意：本方案只新增文件，未改动 `theme.ts` 原有逻辑。**

---

## 一、设计原则

三套风格统一遵循以下三条「舒适阅读」原则，确保横向一致：

1. **单一低饱和度强调色**：每套只用一个去饱和的强调色（暖橙 / 朱砂红 / 青绿），只出现在标题、引用竖条、链接、行内代码、表头，不喧宾夺主。
2. **正文行高 ≥ 1.8**：公众号是手机阅读场景，宽松行高 + 偏大字号（16px）显著降低视觉疲劳。
3. **不使用纯黑**：正文用深灰（#5B5249 / #4A4339 / #3F4A53）而非 #000，背景用米白 / 宣纸白 / 纯白，层次更柔和。

## 三、各风格详细 Token

### 1. 暖阳 · Warm Sun
- **背景**：页面由外层容器提供暖米白 `#FBF6EE`（见画布预览）
- **文字**：正文 `#5B5249`、标题 `#3A332B`、次要 `#6D6359` / `#8A7E70`、引用 `#8A7E70`
- **强调**：`#D98E4F`（h2 文字、引用竖条、链接、表头底 `#FBEBDD`、行内代码底）
- **字号**：h1 25 / h2 19 / h3 17 / 正文 16 / 引用 15 / 行内码 14 / 代码块 13
- **行高**：正文 1.85，标题 1.4–1.45
- **圆角**：卡片 12–16px，引用 8px，代码块 10px（温暖、柔和）

### 2. 素笺 · Ink
- **背景**：宣纸白 `#FCFBF6`，表头 `#F6E4DE`，引用底 `#F6E4DE`
- **文字**：正文 `#4A4339`、标题 `#2B2620`、次要 `#6E665A`、引用 `#6E665A`（斜体）
- **强调**：`#B23A2E` 朱砂红（h2 文字、引用竖条、链接、行内代码）
- **标题字体**：`h1/h2/h3` 使用衬线 `'Noto Serif SC', 'Songti SC', 'SimSun', serif`（需页面加载 Noto Serif SC 或回退系统宋体）
- **字号**：h1 26 / h2 19 / h3 17 / 正文 16 / 引用 15 / 代码块 13
- **行高**：正文 1.9（最松），标题 1.4–1.45
- **圆角**：仅 3–4px（纸感、克制），代码块 4px

### 3. 清露 · Fresh
- **背景**：纯白 `#FFFFFF`，表头 `#E3F2EF`，引用底 `#E3F2EF`
- **文字**：正文 `#3F4A53`、标题 `#28323A`、次要 `#6B7681`、引用 `#6B7681`
- **强调**：`#1F9E8E` 青绿（h2 文字、引用竖条、链接），行内代码文字 `#138A7C`
- **字号**：h1 25 / h2 19 / h3 17 / 正文 16 / 引用 15 / 代码块 13
- **行高**：正文 1.85，标题 1.4–1.45
- **圆角**：卡片 12px，引用 10px，代码块 12px（利落、现代）

> 三套的「代码块」统一用深底浅字（暖阳 `#2E2A26` / 素笺 `#2B2620` / 清露 `#1E2A2E`），保证代码可读性与风格协调。

## 五、给 CodeBuddy 的接入建议

以下由开发侧完成，设计侧已预留好结构化样式，无需重新设计：

1. **注册主题**：在 `theme.ts` 的 `themeList` 中追加三项
   ```ts
   import { warmSunTheme } from './theme-warm-sun';
   import { inkTheme } from './theme-ink';
   import { freshTheme } from './theme-fresh';

   export const themeList: ThemeDefinition[] = [
     { id: 'default', name: '经典', styles: defaultTheme },
     { id: 'grace',   name: '优雅', styles: graceTheme },
     { id: 'simple',  name: '极简', styles: simpleTheme },
     { id: 'modern',  name: '现代', styles: modernTheme },
     { id: 'warm-sun', name: '暖阳', styles: warmSunTheme },
     { id: 'ink',      name: '素笺', styles: inkTheme },
     { id: 'fresh',    name: '清露', styles: freshTheme },
   ];
   ```

2. **处理调色板覆盖**：现有 `buildTheme()` 会用 `paletteList` 覆盖 h2 颜色/边框、引用竖条、链接色、行内代码、表头底色。
   - 方案 A（推荐，最贴合设计）：为这三套各配一个 `paletteList` 项，把 `primary` 设为对应强调色（暖阳 `#D98E4F` / 素笺 `#B23A2E` / 清露 `#1F9E8E`），`primaryLight` 设为对应浅色（`#FBEBDD` / `#F6E4DE` / `#E3F2EF`），`codeInline` 设为强调色，`link` 设为强调色。这样 `buildTheme` 注入的恰好是设计强调色。
   - 方案 B：在 `buildTheme` 中对 `warm-sun` / `ink` / `fresh` 跳过调色板注入，直接返回样式文件里的配色。

3. **字体（仅素笺）**：`ink` 主题 h1/h2/h3 使用了衬线字体，需确保预览页引入了 `Noto Serif SC`（可通过 Google Fonts 或系统宋体回退），否则会回退到系统默认衬线。

4. **下拉菜单**：主题切换下拉的标签已随 `themeList` 的 `name` 自动出现「暖阳 / 素笺 / 清露」。
